# 1. Project Overview

## The Problem

Planning a trip can be complicated because travellers need to manage different aspects of their journey, such as creating an itinerary, checking transportation, managing their budget, communicating with travel companions and handling currency exchange.

This becomes more challenging for group travellers because members may have different preferences, schedules and budgets. Travellers often need to switch between multiple applications to plan their trip, communicate with their group and check currency information.

The main stakeholders are travellers, especially people travelling in groups, as well as their travel companions.

Similar applications such as Google Maps and other travel planning applications provide useful information about locations and transportation. However, users may still need to rely on separate applications for group communication and currency exchange.

## Our Solution

Travel Planner is a travel companion designed to simplify the travel experience by bringing useful travel-related features into one platform.

The application helps users organise their trip and provides supporting features for group travel, including communication through a walkie-talkie and currency exchange information.

Instead of switching between multiple applications, travellers can access these functions within the same travel experience.

### Feature Set

- Travel Planning
- Itinerary Management
- Transport Information
- Group Communication through Walkie-Talkie
- Currency Exchange
- Exchange Location Recommendations

# 3. Design & Prototype

**UI Prototype:** https://www.figma.com/make/BW6GEJv6Iljx8Ylykz6AnH/Travel-Planner?t=Iwu3L3pwSdeyaUaq-1

The prototype focuses on the user interface and interaction flow of the Travel Planner. The key screens demonstrate how users can access travel-related functions and interact with their group during a trip.

## Key Screens

### 1. Travel Planning

Users can provide their travel information and organise their trip through the Travel Planner.

The planning experience is designed to help users manage their travel activities in a more organised way.

### 2. Itinerary

Users can view their planned activities and destinations in an organised itinerary.

The itinerary provides users with a clear overview of their travel plans.

### 3. Group Communication — Walkie-Talkie

The Walkie-Talkie feature allows members of a travel group to communicate using push-to-talk voice communication.

Users can hold the microphone button to send a voice message to their group.

### 4. Currency Exchange

The Currency Exchange feature allows users to check currency conversion and exchange rates while travelling.

Users can enter an amount and view the corresponding value in another currency.

### 5. Exchange Location Recommendations

In addition to checking currency rates, users can discover nearby currency exchange locations.

The prototype provides information such as location, distance, rating, and exchange rate information to help users compare available options.

# 4. What Makes It Different

Travel Planner focuses on the needs of travellers beyond basic itinerary planning by combining travel planning with features designed specifically for group travel.

## Walkie-Talkie Communication

The Walkie-Talkie feature provides quick group communication through a push-to-talk interaction.

This is designed for situations where travelling group members need to communicate quickly while moving between locations.

## Currency Exchange with Location Recommendations

The Currency Exchange feature goes beyond basic currency conversion.

Users can check exchange rates and also discover nearby currency exchange locations, allowing them to make more informed decisions while travelling.

## Integrated Group Travel Experience

The key difference is the combination of these functions within a single travel experience.

Users can plan their trip, communicate with their group and manage currency information without having to rely on separate applications for each activity.
